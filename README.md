# Journey Endurance Strength

Welcome to **Journey Endurance Strength**, a fitness and meal tracking application. This project is a rebranded fork of [wger Workout Manager](https://github.com/wger-project/wger), customized to integrate seamlessly with the main Journey Endurance app.

By separating the strength training and nutrition tracker into this app, we aim to decrease the size of the main Journey Endurance app while still allowing it to pull all necessary data.

## Features

- **Workout Tracking:** Log your strength training sessions, exercises, sets, and reps.
- **Nutrition/Macros:** Track your daily meals and nutritional intake.
- **Integration:** APIs and data structures designed to feed data back into the main Journey Endurance app.
